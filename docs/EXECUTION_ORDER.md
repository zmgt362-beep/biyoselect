## Phase 2 — Deploy

- Connect GitHub repository to Vercel
- Deploy preview
- Verify routes, mobile UX, links and events
- Production deployment

## Phase 3 — First evidence

- Choose one high-intent decision problem using verified current offer economics where available
- Publish one comparison/selector path
- Publish a small number of distribution posts
- Measure selector completion, product views, affiliate clicks and conversions
- Replace estimates with observed data

## Phase 4 — Numeric optimization

Run at least 10 sequential experiments. Each iteration must alter the next hypothesis based on the previous result and track full-funnel economics through net profit/hour.

## Phase 5 — Scale

Scale only paths with evidence of positive economics, repeatability, acceptable compliance/operational risk, and favorable opportunity cost.
