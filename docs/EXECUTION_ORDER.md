# BIYOSELECT Execution Order

## Phase 0 — Ready now

- Business model defined
- Notion data foundation defined
- Application contracts written
- Revenue model and experiment sequence written
- Compliance/data-quality gates written
- Codex queue written

## Phase 1 — Build

- Bootstrap app
- Selector
- Recommendation engine
- Product UI
- Affiliate CTA
- Event tracking
- SEO/content routes
- Required legal/disclosure surfaces
- Test/build

## Phase 2 — Deploy

- Connect GitHub repository to Vercel
- Deploy preview
- Verify routes and events
- Production deployment

## Phase 3 — First evidence

- Choose one high-intent decision problem
- Publish one comparison/selector path
- Publish a small number of distribution posts
- Measure downstream clicks
- Replace hypotheses with observed data

## Phase 4 — Numeric optimization

Run at least 10 sequential experiments. Each iteration must alter the next hypothesis based on the previous result. Stop underperforming channels rather than accumulating work.

## Phase 5 — Scale

Scale only the path with evidence of positive economics, repeatability, and acceptable compliance/operational risk.
