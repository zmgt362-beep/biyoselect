# BIYOSELECT Acquisition Strategy

## Principle

Do not commit to SEO as the only acquisition channel before evidence. Test multiple low-cost routes and let measured profit/hour determine allocation.

## Acquisition hypotheses

### H1 — Decision keywords

Target queries where the user is already comparing products or asking which one to choose. Expected advantage: high purchase intent.

### H2 — Concern/purpose keywords

Target users with a concrete beauty problem and connect the problem directly to a selector or comparison. Expected advantage: broader demand, but potentially lower purchase intent.

### H3 — Social hook → selector

Use short-form content that resolves one concrete choice and routes to a full decision flow. Expected advantage: fast feedback; downside: platform volatility.

### H4 — Trend/product trigger

React to products gaining attention and provide a neutral comparison/selection layer. Expected advantage: fast demand capture; downside: short shelf life.

### H5 — Influencer/topic bridge

Build pages around products already introduced by creators or widely discussed. The service adds selection logic rather than copying the creator's recommendation.

## Measurement

Every acquisition experiment must be connected to downstream behavior. Impressions and views are diagnostic metrics, not success criteria.

Primary comparison: `net profit / operating hour`.

Secondary: visit rate, selector completion, affiliate CTR, conversion rate, approved revenue, repeatability.

## First execution rule

Start with the smallest number of pages/posts necessary to create measurable signal. Expand only the themes whose downstream economics beat the current baseline.
