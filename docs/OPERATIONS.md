# BIYOSELECT Operations

## Daily operating loop

1. Check current state and blockers.
2. Check highest-priority experiment.
3. Validate product/affiliate facts before publishing or changing CTAs.
4. Publish/test the smallest change that can produce evidence.
5. Record results in Notion.
6. Update the next action based on observed economics.

## Weekly review

Review:

- traffic by source
- selector completion
- product views
- affiliate CTR
- conversions
- approved revenue
- cost
- operating hours
- net profit/hour
- experiments continued/improved/stopped

## Data freshness

Price, availability, affiliate terms, reward, and approval status can change. Store confirmation dates in Notion and avoid treating stale values as current.

## Failure policy

If a dependency is unavailable, document the blocker and continue with independent work. Do not fabricate credentials, URLs, API results, or private account data.
