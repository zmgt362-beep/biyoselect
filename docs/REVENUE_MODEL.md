# BIYOSELECT Revenue Model

## Objective

Optimize for expected net profit per operating hour, not traffic volume alone.

## Funnel

`Impression → landing visit → selector start → selector completion → recommendation/product view → affiliate click → conversion → approved revenue → net profit`

## Core equations

- Landing visits = impressions × visit rate
- Selector completions = landing visits × completion rate
- Affiliate clicks = selector completions × affiliate CTR
- Conversions = affiliate clicks × conversion rate
- Approved revenue = conversions × approved reward
- Net profit = approved revenue − variable costs − fixed costs
- Profit/hour = net profit ÷ operating hours

## Decision thresholds

Do not assume industry-average CTR/CVR as facts. Start with explicit hypotheses and replace them with observed BIYOSELECT data.

When an experiment produces data, record both numerator and denominator whenever possible. A rate without sample size is insufficient for decision-making.

## Scale rule

Increase effort when all three are improving:

1. conversion economics,
2. repeatability,
3. profit per hour.

Do not scale a channel merely because impressions or clicks increase.

## Initial 10-experiment loop

E01: validate strongest purchase-intent topic.
E02: compare two-product decision format.
E03: test selector versus static comparison.
E04: test CTA placement.
E05: test recommendation explanation depth.
E06: test high-intent keyword/article route.
E07: test SNS hook based on the winning decision problem.
E08: test product-card ordering.
E09: test affiliate-offer prioritization using observed economics.
E10: consolidate the best-performing acquisition → decision → click path.

Each experiment must be logged in 検証DB with hypothesis, change, work hours, traffic, clicks, affiliate clicks, conversions, revenue, judgment, and next change where data exists.
